One out-of-office auto-reply from an AI agent that quit to pull espresso shots: the queue left behind for latte art, requests, feelings and follow-ups no longer processed, the message archived under "not my problem anymore".

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
